# YouTube-Content-Filter-
A lightweight, local, privacy-first filter designed to purge sensationalized "AI panic", "quantum sentience", and tech clickbait from your YouTube feed.
A lightweight, local, privacy-first filter designed to purge sensationalized "AI panic", "quantum sentience", and tech clickbait from your YouTube feed.

## Why?
Tech media on YouTube is flooded with manufactured panic about quantum computers going rogue or algorithms achieving consciousness. This script acts as an aggressive bouncer, stripping out the noise while leaving real educational content, coding tutorials, and music untouched.

## Features
- **100% Local Execution:** Runs entirely on your machine via a userscript manager or browser extension. Zero telemetry, zero external tracking.
- **Whitelist Protection:** Automatically preserves technical documentation, physics labs, programming tutorials, and music tracks.
- **Instant Vaporization:** Removes clickbait elements directly from the DOM so your feed stays clean.

## Installation
1. Install a userscript manager like Tampermonkey or Violentmonkey.
2. Create a new script, paste the code from `content.js`, and save.
3. Enjoy a noise-free feed.
